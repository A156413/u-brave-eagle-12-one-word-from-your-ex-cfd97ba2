One word from your ex: **ghosted**. No fight, no goodbye — just read receipts and silence. The word every ex has thought, and every one of us has lived through from one side or the other.

## Run it

```sh
python3 main.py
```

It prints the word and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
